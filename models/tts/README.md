# Модели синтеза речи (Text-to-Speech)

Папка зарезервирована для локального озвучивания ответов и уведомлений ассистента без обращения к внешним серверам.

### Поддерживаемые архитектуры:
- **Piper TTS** (`.onnx` + `.onnx.json`) — ультралегковесный и естественный синтез речи для Linux / Windows (потребляет <50 MB RAM)
- **VITS** / **Silero TTS** (`.pt`, `.onnx`)
- **Kokoro-82M** ONNX

### Структура файлов:
- `ru_RU-dmitri-medium.onnx` — веса модели голоса
- `ru_RU-dmitri-medium.onnx.json` — конфигурация фонетизатора и карты фонем
- `ru_RU-irina-medium.onnx` — альтернативный женский голос
