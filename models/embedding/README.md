# Модели эмбеддингов (Vector Embeddings)

Папка предназначена для локальных моделей плотных векторных представлений текста (Semantic Search & RAG).

### Задачи моделей эмбеддингов:
1. **Умная маршрутизация запросов**: вычисление семантической близости запроса к описаниям модулей и инструментов без жёстких ключевых слов.
2. **Локальная база знаний**: мгновенный поиск по заметкам, сниппетам кода и файлам в `storage/`.

### Поддерживаемые модели:
- `bge-small-ru-v1.5.onnx` (~130 MB, 384 dimensions)
- `all-MiniLM-L6-v2.onnx` (~90 MB, 384 dimensions)
- `bge-m3.onnx` (мультиязычная с поддержкой 8192 токенов)
