# Airi — Документация Backend и Архитектуры Системы

Добро пожаловать в официальную документацию системы **Airi (Personal Screen Assistant)**.

Airi спроектирована как компактный, модульный оверлей-ассистент для рабочего стола с локальным инференсом FunctionGemma, динамической файловой системой модулей, строгой проверкой контрольных сумм и специализированной подсистемой плавающих окон **Views**.

## Структура директорий Backend и модулей

```text
/
├── server.ts                    # Главная точка входа Express-сервера и SSE-потоков
├── server/                      # Ядро backend-логики
│   ├── modulesRegistry.ts       # Реестр и загрузчик модулей, расчет хешей SHA-256
│   ├── functionGemmaService.ts  # Сервис вызова и симуляции FunctionGemma
│   ├── iniHelper.ts             # Парсер и сериализатор конфигурационных файлов INI
│   ├── storageService.ts        # Служба управления постоянным хранилищем /storage
│   ├── loggerService.ts         # Журнал вызовов и оценивания точности
│   └── initialModules.ts        # Базовые модули и шаблоны инструментов
├── backend/docs/                # Документация backend (данный раздел)
├── modules/                     # Директория пользовательских модулей
│   ├── time/                    # Модуль времени и даты
│   │   ├── module.json          # Манифест модуля
│   │   ├── config.ini           # Пользовательская конфигурация параметров
│   │   └── time_tool.js         # Исполняемый код инструмента get_current_time
│   ├── system/                  # Модуль мониторинга хоста
│   ├── notes/                   # Заметки и хранилище
│   ├── calc/                    # Калькулятор и вычисления
│   └── browser/                 # Браузерные утилиты
└── storage/                     # Физическая папка для данных инструментов
```

## Ключевые концепции

- **Минималистичный HUD**: Окно запроса является единственным плавающим окном ввода на экране.
- **Окна отображения (Views)**: Инструменты выводят структурированные визуальные виджеты (время, метрики хоста, списки, ключ-значение) прямо на рабочий стол.
- **Поведение рабочей области**: Клик по рабочему столу немедленно закрывает все незакрепленные окна (включая окно HUD, если оно не закреплено).
- **Критическая сумма сигнатур**: Защита от рассогласования модели и инструментов при обучении FunctionGemma.
- **Аудио-отклик**: Тонкие ненавязчивые звуковые сигналы при вызове инструментов и завершении операций.
